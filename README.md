# Create Resume

![React](https://img.shields.io/badge/React-19-61DAFB) ![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6) ![Vite](https://img.shields.io/badge/Vite-5.x-646CFF)

Create Resume is a modern React + TypeScript app for building professional resumes through a guided multi-step form. It includes a live preview, editable sections, local autosave, and support for exporting a polished resume.

The backend for PDF generation and resume processing lives in a separate repository:

https://github.com/Gitanuj993/create-resume-backend

## Features

- Guided flow for personal details, social links, summary, skills, experience, projects, achievements, and education
- Real-time resume preview while editing
- Section reordering for customizing the final document
- Local auto-save using browser storage
- Sample resume content and reset tools
- PDF export integration via the backend API

## Local Setup

### 1. Clone the project

```bash
git clone https://github.com/<your-username>/create-resume-ui.git
cd create-resume-ui
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the frontend locally

```bash
npm run dev
```

The app runs locally at:

```text
http://localhost:3000
```

### 4. Start the backend

This frontend proxies `/resume` requests to the backend service running locally at:

```text
http://localhost:8000
```

Make sure the backend repository is running before generating the PDF:

https://github.com/Gitanuj993/create-resume-backend

If needed, override the default target with a local environment variable:

```env
RESUME_API_TARGET=http://localhost:8000
```

## Notes

- The frontend depends on a separate backend for PDF generation.
- The Vite dev server proxies resume-related requests to the backend.
- For deployment, ensure the backend service is reachable from your hosting environment.
